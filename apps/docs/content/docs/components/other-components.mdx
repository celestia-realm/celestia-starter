The package also ships these components without live previews on this page:

| Component | Import | Notes |
|-----------|--------|-------|
| `direction` | `@workspace/ui/components/direction` | `DirectionProvider` + `useDirection` for RTL support |
| `toast` | `@workspace/ui/components/toast` | Base UI toast primitives (`toast`, `Toaster`, `ToastViewport`); prefer `sonner` for app toasts |
| `sidebar` | `@workspace/ui/components/sidebar` | Full app-shell sidebar (see the dashboard feature) |
| `attachment`, `bubble`, `marker`, `message`, `message-scroller` | `@workspace/ui/components/<name>` | Chat/AI message UI primitives |
