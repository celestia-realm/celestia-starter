title: Components
description: Reusable UI components from the @workspace/ui package, rendered live
---

All components live in `packages/ui/src/components` and are imported via the `@workspace/ui` package alias. Every component is built on Base UI primitives, styled with Tailwind CSS, and supports the `className` prop for overrides. Icons come from `@phosphor-icons/react`.

## Installation

The `@workspace/ui` package is already a workspace dependency. To add a new shadcn/ui component to the shared library:

```bash
pnpm dlx shadcn@latest add button -c apps/web
```

## Chart

Accessible, themeable charts built on `recharts`. `ChartContainer` injects color variables from a `ChartConfig`.

<ChartPreview />

```tsx
import { Bar, BarChart, CartesianGrid, XAxis } from "recharts"
import {
  ChartContainer,
  ChartTooltip,
  ChartTooltipContent,
  type ChartConfig,
} from "@workspace/ui/components/chart"

const chartData = [
  { month: "January", desktop: 186 },
  { month: "February", desktop: 305 },
]

const chartConfig = {
  desktop: { label: "Desktop", color: "var(--chart-1)" },
} satisfies ChartConfig

<ChartContainer config={chartConfig} className="h-48 w-full">
  <BarChart data={chartData}>
    <CartesianGrid vertical={false} />
    <XAxis dataKey="month" tickLine={false} axisLine={false} />
    <ChartTooltip content={<ChartTooltipContent />} />
    <Bar dataKey="desktop" fill="var(--color-desktop)" radius={4} />
  </BarChart>
</ChartContainer>
```

Chart colors are defined by the `--chart-1` … `--chart-5` tokens in `globals.css`. Also exports `ChartLegend` / `ChartLegendContent`.

## Menu

A dropdown menu built on the Base UI `Menu` compound component. Supports items, sub-menus, checkbox items, radio groups, groups, separators, and keyboard shortcuts.

<MenuPreview />

```tsx
import { Button } from "@workspace/ui/components/button"
import {
  Menu,
  MenuCheckboxItem,
  MenuGroup,
  MenuGroupLabel,
  MenuItem,
  MenuPopup,
  MenuPortal,
  MenuPositioner,
  MenuRadioGroup,
  MenuRadioItem,
  MenuSeparator,
  MenuShortcut,
  MenuSub,
  MenuSubTrigger,
  MenuTrigger,
} from "@workspace/ui/components/menu"

<Menu>
  <MenuTrigger render={<Button variant="outline" />}>Open Menu</MenuTrigger>
  <MenuPortal>
    <MenuPositioner sideOffset={8} align="start">
      <MenuPopup>
        <MenuGroup>
          <MenuGroupLabel>Actions</MenuGroupLabel>
          <MenuItem>
            New Tab
            <MenuShortcut>⌘T</MenuShortcut>
          </MenuItem>
          <MenuSub>
            <MenuSubTrigger>Share</MenuSubTrigger>
            <MenuPortal>
              <MenuPositioner sideOffset={4}>
                <MenuPopup>
                  <MenuItem>Copy Link</MenuItem>
                </MenuPopup>
              </MenuPositioner>
            </MenuPortal>
          </MenuSub>
        </MenuGroup>
        <MenuSeparator />
        <MenuCheckboxItem checked={checked} onCheckedChange={setChecked}>
          Status Bar
        </MenuCheckboxItem>
        <MenuRadioGroup value={panel} onValueChange={setPanel}>
          <MenuRadioItem value="top">Panel Top</MenuRadioItem>
        </MenuRadioGroup>
        <MenuSeparator />
        <MenuItem variant="destructive">Delete</MenuItem>
      </MenuPopup>
    </MenuPositioner>
  </MenuPortal>
</Menu>
```

| Component | Purpose |
|-----------|---------|
| `Menu` | Root — manages open/close state |
| `MenuTrigger` | Toggle button (use `render` to customize the element) |
| `MenuPortal` | Renders the popup into a portal |
| `MenuPositioner` | Positions the popup (`sideOffset`, `align`, `side`) |
| `MenuPopup` | The visible menu container |
| `MenuItem` | An action item (`variant="destructive"`, `inset`) |
| `MenuCheckboxItem` | Toggleable item (`checked`, `onCheckedChange`) |
| `MenuRadioGroup` / `MenuRadioItem` | Single-select group (`value`, `onValueChange`) |
| `MenuSub` / `MenuSubTrigger` | Nested sub-menu |
| `MenuGroup` / `MenuGroupLabel` | Grouping with a label |
| `MenuSeparator` | Visual divider |
| `MenuShortcut` | Keyboard hint aligned to the right |
